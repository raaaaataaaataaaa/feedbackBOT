# Бот обратной связи для Telegram

Простой бот, который позволяет пользователям отправлять сообщения администратору.

## Функционал

- **Для пользователей:**
  - Кнопка "📝 Написать сообщение" для отправки сообщения администратору
  - Поддержка текста, фото, документов и голосовых сообщений
  - Получение ответов от администратора

- **Для администратора:**
  - Получение всех сообщений от пользователей
  - Возможность отвечать пользователям через реплай (ответ на сообщение)
  - Информация об отправителе (его Telegram ID)

## Установка

1. **Получите токен бота:**
   - Откройте @BotFather в Telegram
   - Отправьте команду `/newbot`
   - Следуйте инструкциям и получите токен

2. **Узнайте свой Telegram ID:**
   - Откройте @userinfobot в Telegram
   - Отправьте любую команду
   - Скопируйте ваш ID (число)

3. **Настройте бота:**

   Откройте файл `feedback_bot.py` и замените:
   ```python
   BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"  # вставьте токен от BotFather
   ADMIN_ID = YOUR_ADMIN_ID_HERE      # вставьте ваш ID (число без кавычек)
   ```

4. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

5. **Запустите бота:**
   ```bash
   python feedback_bot.py
   ```

## Как использовать

### Для администратора:
1. Запустите бота командой `/start`
2. Нажмите кнопку "👤 Получить сообщение"
3. Когда придёт сообщение от пользователя, ответьте на него реплаем
4. Ваш ответ будет отправлен пользователю

### Для пользователей:
1. Запустите бота командой `/start`
2. Нажмите кнопку "📝 Написать сообщение"
3. Напишите ваше сообщение
4. Ожидайте ответа от администратора

## Примечания

- Бот работает в режиме polling (опрос сервера Telegram)
- Все сообщения сохраняются только в памяти (при перезапуске бота история теряется)
- Для продакшена рекомендуется использовать вебхуки и базу данных
